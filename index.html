    关于默认阵容

    参赛配置

    编辑坦克

    定义一个同步的 function decide(state)，返回移动、转向和开火指令。炮筒随车身转动。
    JavaScript API

    策略指南

    为每辆坦克提供一个 function decide(state)。策略在每局开始时重新载入，每隔 0.125 秒收到一次战场快照。函数可以用文件内的变量保存本局状态。

    输入数据
    state.self
    state.tanks    		自己和所有坦克。每辆有 id, x, y, angle, turret, cooldown, alive, kills。angle 是车身和炮筒的共同朝向。turret 是为旧策略保留的同一读数。冷却时间以秒计。
    state.bullets场上弹丸，每枚有 id, ownerId, x, y, vx, vy, bounces。速度单位为游戏像素每秒。
    state.mapid, width, height, cols, rows, cellSize, wallWidth, walls, exits。walls 是墙的中心线段数组 [x1,y1,x2,y2]。exits[i] 是第 i 个格子能直接进入的相邻格子编号，格子按行从 0 开始编号。
    state.tick
    state.round
    state.timeLeft    		120 Hz 的模拟帧编号、从 1 开始的局数、本局剩余秒数。坐标原点在左上角，向右为 0 弧度，顺时针为正。

    返回 { throttle, turn, fire }。throttle 和 turn 取 −1 至 1，负值表示倒车和逆时针转向。用 turn 把车身转向目标，再用 fire: true 沿正前方开火。三项均可省略。旧策略返回的 aim 会被忽略。

    弹丸会反弹，命中一次即淘汰。反弹自击无分。每枚弹丸最长存在 8 个游戏秒，每辆坦克最多同时有 5 枚弹丸在场。45 秒仍有多辆幸存时判平局，保留击杀分。脚本在隔离环境同步运行，可使用标准 JavaScript 和 Math。每次决策时限为 240 毫秒，报错或超时的坦克退出当前局。
